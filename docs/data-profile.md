# IEEE-CIS Data Profile

This document is generated by:

```bash
uv run python scripts/profile_ieee_cis.py
```

Place `train_transaction.csv` and `train_identity.csv` in `data/raw` before running the
profiler. The generated report summarizes fraud imbalance, transaction amounts, ProductCD
fraud rates, identity join coverage, missingness, categorical cardinality, time-window drift,
and leakage or serving-compatibility risks.

## Modeling Implications

- CatBoost is expected to be a strong candidate when the profile confirms high-cardinality
  categorical features and meaningful missingness.
- LightGBM is expected to be a fast benchmark candidate, but categorical encoding choices should
  follow the cardinality and missingness profile.
- Calibration should be evaluated on later time windows when the profile shows fraud-rate drift.
