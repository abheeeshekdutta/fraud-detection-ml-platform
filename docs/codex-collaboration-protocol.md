# Codex Collaboration Protocol

This document records the working rhythm requested for this project.

## After Each Task

When an implementation task is completely finished, Codex should stop and provide a short report before continuing. The report should focus on the actual implementation work, not routine housekeeping, unless the housekeeping was the task itself.

The report should include:

- What changed
- Problems faced
- Solutions applied
- Verification performed
- New learnings that may be reusable in future projects
- Suggested next task, if there is an obvious one

Codex should ask for permission before continuing to the next task.

## GitHub Pushes

Codex can push completed work to the remote GitHub repository when:

- The repository has a configured remote
- The local environment is authenticated with GitHub
- The user explicitly gives permission to push

Codex should not push automatically after a task unless the user has clearly requested that behavior for that specific task or session.

Before pushing, Codex should summarize:

- The branch being pushed
- The commits or changes included
- The remote target

After each completed task, add any durable lessons here that could help future projects.

- GitHub publishing should be treated as a separate, permissioned step after local verification, not as an automatic continuation.
